# Модуль OpenCart 3.0 для України

## Чекліст інтеграції:
- [x] Встановіть модуль.
- [x] Передайте тех підтримці PSP Platon посилання для коллбеків.
- [x] Проведіть оплату використовуючи тестові реквізити.

## Встановлення:

* Розпакуйте архів в корінь сайту.

* В адмін панелі перейдіть в Extensions → Payments → Platon.

* Натисніть "Install", потім "Edit".

* В налаштуваннях вкажіть ключ і пароль. Налаштуйте статуси транзакцій Pending для Order Status та Refunded для Refunded Order Status.

* Встановіть значення платіжного методу в статус Enabled.

## Посилання для коллбеків:
https://ВАШ_САЙТ/index.php?route=extension/payment/platon/callback
